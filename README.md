# Venkat & Bhavya — Wedding Invitation

An interactive digital Indian wedding invitation celebrating the union of Venkat and Bhavya on December 2 & 3, 2026.

## Features

- **Interactive Opening Experience**: Envelope and traditional entrance animation with auspicious mantras and toranam.
- **Wedding Schedule & Timelines**: Full schedule for the evening Reception and sacred morning Muhurtham.
- **Live Countdown Timer**: Real-time days, hours, minutes, and seconds remaining until the ceremony.
- **Venue & Map Directions**: Direct navigation link and address for guests.
- **Traditional Telugu & South Indian Aesthetics**: Authentic motifs (Ganesha, brass deepam, jasmine garlands, kolam, and temple arch) paired with typography and responsive styling.

## Tech Stack

- **Framework**: [TanStack Start](https://tanstack.com/start) & [TanStack Router](https://tanstack.com/router)
- **UI & Components**: React 19, TypeScript, Tailwind CSS, Framer Motion, Radix UI
- **Build Tool**: Vite
- **Testing**: Vitest & React Testing Library

## Getting Started

### Prerequisites

Node.js (v18+) and npm.

### Installation

```bash
npm install
```

### Development

To start the local development server:

```bash
npm run dev
```

### Production Build

To build the project for production:

```bash
npm run build
npm run preview
```

### Running Tests

```bash
npm test
```
